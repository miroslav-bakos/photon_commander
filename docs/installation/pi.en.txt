RASPBERRY PI 5 ARM64 — PHOTON COMMANDER 0.0.1
Use the supplied ARM64 DEB on Raspberry Pi OS 64-bit based on Debian 12 (bookworm) or newer. The planned native build baseline is Debian 12 / glibc 2.36; check the supplied ci-build-evidence.json for the actual package build and bundled ELF requirements. A newer operating system alone does not guarantee compatibility. Installation and operation on actual Raspberry Pi 5 hardware remain pending validation. No x86-64 or Windows package works on this target. The generic package does not require an external SSD. This guide does not certify physical observing performance.
Verify: sha256sum -c filename.deb.sha256. Install: sudo apt install ./filename.deb. Use the actual supplied filenames. Application: /opt/photon-commander; data: /var/lib/photon-commander; service overrides: /etc/photon-commander/environment. Check: systemctl status photon-commander. Open http://PI-IP:7777 on the LAN, substituting this Pi's actual address. photon.local:7777 is only usable if the hostname is advertised and resolves on your LAN.
The service runs as photon-commander and protects home directories. Create captures with: sudo install -d -o photon-commander -g photon-commander -m 0770 /var/lib/photon-commander/captures. Save that server-side folder in the wizard. Do not weaken service protections for a home folder.
Install Linux ARM64 ASTAP and D20; add W08 for a wide camera. Official instructions: https://www.hnsky.org/astap.htm and https://sourceforge.net/projects/astap-program/files/ . Save paths in the wizard and check detected status. SSC_ASTAP_CLI and SSC_ASTAP_DATA_DIR service overrides belong in /etc/photon-commander/environment; restart using sudo systemctl restart photon-commander after changing environment. Ensure the service account can read program/database files. FFmpeg is separate if video is needed.
A packaged backend includes DE440s. A source checkout requires data/ephemeris/de440s.bsp on this Pi before startup, downloaded from https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp . Repair a missing/corrupt packaged kernel using the exact error path or rebuild with correct inputs, then restart. Do not download it onto the controlling phone.
Update: stop captures, sudo systemctl stop photon-commander, and back up /var/lib/photon-commander and separately stored images. Run sudo apt install ./new-filename.deb; packaging restarts the service. Recheck status and the browser. Uninstall: sudo apt remove photon-commander. User data and the service account remain; delete data only intentionally.
Startup logs: journalctl -u photon-commander -n 100 --no-pager. Guided setup, Station Mode, firmware caution, pairing, Tailscale and observing use: docs/getting-started.en.md. Do not expose the HTTP port directly to the internet. Review logs and attachments for private information before sharing. No automatic firmware update or hardware validation is implied.
