LINUX x86-64 — KANDIDÁT PHOTON COMMANDER
Natívny kandidát sa zostavuje na Ubuntu 22.04; existujúci nástroj balenia kontroluje požiadavky glibc. Inštalácia a skutočná hardvérová kompatibilita ešte čakajú na overenie. Balík nie je podpísaný; kontrolný súčet nie je podpis totožnosti. Použite dodaný balík a jeho súbor SHA256: sha256sum -c filename.sha256.
Pre dodaný DEB použite sudo apt install ./filename.deb, pre RPM sudo dnf install ./filename.rpm. Vyberte skutočne dodaný formát; desktopový CI postup teraz poskytuje AppImage, nie DEB/RPM. Jeho návod je appimage.sk.txt.
Bežná aplikácia DEB/RPM: /opt/photon-commander. Údaje: /var/lib/photon-commander. Služba: photon-commander. Prostredie: /etc/photon-commander/environment. Otvorte http://HOST-IP:7777 v LAN so skutočnou adresou servera. Chránená služba nemôže zapisovať do domovského priečinka; priečinok snímok vytvorte pod jej údajmi s vlastníkom photon-commander.
Pred aktualizáciou zastavte snímanie aj službu a zálohujte údaje i snímky inde. Nainštalujte nový overený balík a skontrolujte službu a prehliadač. Odinštalujte cez sudo apt remove photon-commander alebo sudo dnf remove photon-commander podľa formátu. Údaje zostanú; vymažte ich iba zámerne.
Sieť, upozornenia na firmvér, nastavenie, ASTAP+D20/W08, DE440s, párovanie a pozorovanie: docs/getting-started.sk.md. Požadované astronomické údaje sú v balíku; chýbajúce súbory sú chybou, nesťahujú sa automaticky. Kľúče potrebujú dostupnú odomknutú kľúčenku servera. Logy: journalctl -u photon-commander -n 100 --no-pager. Pred zdieľaním overte súkromné údaje v hlásení a prílohách.
