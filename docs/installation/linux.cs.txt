LINUX x86-64 — KANDIDÁT PHOTON COMMANDER
Nativní kandidát se sestavuje na Ubuntu 22.04; existující balicí nástroj kontroluje požadavky glibc. Instalace a skutečná hardwarová kompatibilita ještě čekají na ověření. Balíček není podepsán; kontrolní součet není podpis totožnosti. Použijte dodaný balíček a jeho soubor SHA256: sha256sum -c filename.sha256.
Pro dodaný DEB použijte sudo apt install ./filename.deb, pro RPM sudo dnf install ./filename.rpm. Vyberte skutečně dodaný formát; desktopový CI postup nyní poskytuje AppImage, ne DEB/RPM. Jeho návod je appimage.cs.txt.
Běžná aplikace DEB/RPM: /opt/photon-commander. Data: /var/lib/photon-commander. Služba: photon-commander. Prostředí: /etc/photon-commander/environment. Otevřete http://HOST-IP:7777 v LAN se skutečnou adresou serveru. Chráněná služba nezapisuje do domovské složky; složku snímků vytvořte pod jejími daty s vlastníkem photon-commander.
Před aktualizací zastavte snímání i službu a zálohujte data a snímky jinde. Nainstalujte nový ověřený balíček a zkontrolujte službu a prohlížeč. Odinstalujte přes sudo apt remove photon-commander nebo sudo dnf remove photon-commander podle formátu. Data zůstanou; smažte je pouze záměrně.
Síť, upozornění na firmware, nastavení, ASTAP+D20/W08, DE440s, párování a pozorování: docs/getting-started.cs.md. Požadovaná astronomická data jsou v balíčku; chybějící soubory jsou chybou, nestahují se automaticky. Klíče potřebují dostupnou odemčenou klíčenku serveru. Logy: journalctl -u photon-commander -n 100 --no-pager. Před sdílením ověřte soukromé údaje v hlášení a přílohách.
