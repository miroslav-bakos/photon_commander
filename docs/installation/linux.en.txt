LINUX x86-64 — PHOTON COMMANDER CANDIDATE
This native candidate is built on Ubuntu 22.04, with glibc requirements checked by the existing package builder. Installation and actual hardware compatibility remain pending validation. It is unsigned; do not treat a checksum as an identity signature. Use the supplied package and matching SHA256 file; verify with sha256sum -c filename.sha256.
For a supplied DEB use sudo apt install ./filename.deb; for a supplied RPM use sudo dnf install ./filename.rpm. Use the format actually supplied; the desktop CI workflow currently supplies AppImage, not DEB/RPM. See appimage.en.txt for that artifact.
Generic DEB/RPM application: /opt/photon-commander. User data: /var/lib/photon-commander. Service: photon-commander. Overrides: /etc/photon-commander/environment. Open http://HOST-IP:7777 on the LAN, replacing HOST-IP with the actual host address. A home directory is not writable by the protected service; create a capture folder under its data directory, owned by photon-commander.
Before updating, stop captures, stop the service and back up data plus separately chosen images. Install the new verified package, then check service status and browser. Uninstall with sudo apt remove photon-commander or sudo dnf remove photon-commander matching your package. Data remains; delete it only deliberately.
Follow docs/getting-started.en.md for networking, firmware cautions, setup, ASTAP+D20/W08, DE440s, pairing and observing. Required packaged astronomy assets are included; missing assets are errors, not automatic downloads. API keys need the host's available unlocked keyring. Logs: journalctl -u photon-commander -n 100 --no-pager. Review report text and attachments for private information before sharing.
