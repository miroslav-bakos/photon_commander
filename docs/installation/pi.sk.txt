RASPBERRY PI 5 ARM64 — PHOTON COMMANDER 0.0.1
Použite dodaný ARM64 DEB na Raspberry Pi OS 64-bit založenom na Debian 12 (bookworm) alebo novšom. Plánovaný základ natívneho zostavenia je Debian 12 / glibc 2.36; skutočné zostavenie balíka a požiadavky pribalených ELF sú uvedené v dodanom ci-build-evidence.json. Novší operačný systém sám nezaručuje kompatibilitu. Inštalácia a prevádzka na skutočnom hardvéri Raspberry Pi 5 ešte čakajú na overenie. Balík x86-64 ani Windows tu nefunguje. Bežný balík nevyžaduje externý SSD. Návod nepotvrdzuje fyzické pozorovanie.
Overte: sha256sum -c filename.deb.sha256. Nainštalujte: sudo apt install ./filename.deb. Použite skutočné dodané názvy súborov. Aplikácia: /opt/photon-commander; údaje: /var/lib/photon-commander; prostredie služby: /etc/photon-commander/environment. Stav: systemctl status photon-commander. V LAN otvorte http://PI-IP:7777, kde PI-IP je skutočná adresa tohto Pi. photon.local:7777 funguje iba ak sa názov oznamuje a sieť ho rozpozná.
Služba beží ako photon-commander a chráni domovské priečinky. Vytvorte snímky: sudo install -d -o photon-commander -g photon-commander -m 0770 /var/lib/photon-commander/captures. Túto serverovú cestu uložte v sprievodcovi. Kvôli domovskému priečinku neoslabujte ochranu služby.
Nainštalujte Linux ARM64 ASTAP a D20; pre širokouhlú kameru aj W08. Oficiálne návody: https://www.hnsky.org/astap.htm a https://sourceforge.net/projects/astap-program/files/ . Uložte cesty v sprievodcovi a overte stav. Premenné SSC_ASTAP_CLI a SSC_ASTAP_DATA_DIR patria do /etc/photon-commander/environment; po zmene reštartujte cez sudo systemctl restart photon-commander. Účet služby musí vedieť čítať program aj databázu. FFmpeg pre video sa inštaluje samostatne.
Zostavený backend obsahuje DE440s. Zdrojová verzia potrebuje data/ephemeris/de440s.bsp na tomto Pi pred spustením: https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp . Pri chýbajúcom alebo poškodenom súbore opravte balík podľa presnej chyby alebo ho zostavte so správnym vstupom a reštartujte. Súbor nepatrí na ovládací telefón.
Aktualizácia: zastavte snímanie, sudo systemctl stop photon-commander a zálohujte /var/lib/photon-commander aj snímky inde. Spustite sudo apt install ./new-filename.deb; balík reštartuje službu. Overte stav a prehliadač. Odinštalovanie: sudo apt remove photon-commander. Údaje a účet služby zostanú; vymažte ich iba zámerne.
Logy: journalctl -u photon-commander -n 100 --no-pager. Sprievodca, Station Mode, upozornenie na firmvér, párovanie, Tailscale a používanie: docs/getting-started.sk.md. Nevystavujte HTTP port priamo internetu. Pred zdieľaním skontrolujte súkromné údaje v logoch a prílohách. Návod nepotvrdzuje aktualizáciu firmvéru ani hardvérovú validáciu.
