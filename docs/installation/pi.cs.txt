RASPBERRY PI 5 ARM64 — PHOTON COMMANDER 0.0.1
Použijte dodaný ARM64 DEB na Raspberry Pi OS 64-bit založeném na Debian 12 (bookworm) nebo novějším. Plánovaný základ nativního sestavení je Debian 12 / glibc 2.36; skutečné sestavení balíčku a požadavky přibalených ELF jsou uvedeny v dodaném ci-build-evidence.json. Novější operační systém sám nezaručuje kompatibilitu. Instalace a provoz na skutečném hardwaru Raspberry Pi 5 ještě čekají na ověření. Balíček x86-64 ani Windows zde nefunguje. Běžný balíček nevyžaduje externí SSD. Návod nepotvrzuje fyzické pozorování.
Ověřte: sha256sum -c filename.deb.sha256. Instalujte: sudo apt install ./filename.deb. Použijte skutečné dodané názvy souborů. Aplikace: /opt/photon-commander; data: /var/lib/photon-commander; prostředí služby: /etc/photon-commander/environment. Stav: systemctl status photon-commander. V LAN otevřete http://PI-IP:7777, kde PI-IP je skutečná adresa tohoto Pi. photon.local:7777 funguje pouze při oznamování a rozpoznání názvu v síti.
Služba běží jako photon-commander a chrání domovské složky. Vytvořte snímky: sudo install -d -o photon-commander -g photon-commander -m 0770 /var/lib/photon-commander/captures. Tuto serverovou cestu uložte v průvodci. Kvůli domovské složce neoslabujte ochranu služby.
Nainstalujte Linux ARM64 ASTAP a D20; pro širokoúhlou kameru také W08. Oficiální návody: https://www.hnsky.org/astap.htm a https://sourceforge.net/projects/astap-program/files/ . Uložte cesty v průvodci a ověřte stav. Proměnné SSC_ASTAP_CLI a SSC_ASTAP_DATA_DIR patří do /etc/photon-commander/environment; po změně restartujte přes sudo systemctl restart photon-commander. Účet služby musí číst program i databázi. FFmpeg pro video se instaluje samostatně.
Sestavený backend obsahuje DE440s. Zdrojová verze potřebuje data/ephemeris/de440s.bsp na tomto Pi před spuštěním: https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp . Chybějící nebo poškozený soubor opravte podle přesné chyby serveru nebo balíček sestavte se správným vstupem a restartujte. Soubor nepatří na ovládací telefon.
Aktualizace: zastavte snímání, sudo systemctl stop photon-commander a zálohujte /var/lib/photon-commander i snímky jinde. Spusťte sudo apt install ./new-filename.deb; balíček restartuje službu. Ověřte stav a prohlížeč. Odinstalování: sudo apt remove photon-commander. Data a účet služby zůstanou; smažte je pouze záměrně.
Logy: journalctl -u photon-commander -n 100 --no-pager. Průvodce, Station Mode, upozornění na firmware, párování, Tailscale a používání: docs/getting-started.cs.md. Nevystavujte HTTP port přímo internetu. Před sdílením zkontrolujte soukromé údaje v logu a přílohách. Návod nepotvrzuje aktualizaci firmwaru ani hardwarovou validaci.
