WINDOWS x64 — PHOTON COMMANDER 0.0.1
Use the supplied private Windows x64 installer. This guide does not claim code signing, compatibility with every Windows version or observing validation. Verify its SHA-256 with PowerShell: Get-FileHash <installer.exe> -Algorithm SHA256; compare with the supplied checksum. Replace the placeholder with the actual filename.
Run setup for your Windows user account. Application: %LOCALAPPDATA%\Programs\Photon Commander. User data: %LOCALAPPDATA%\Photon Commander. Launch the Photon Commander shortcut and open http://127.0.0.1:7777. The backend console must remain running. Do not launch a second backend on the same port. This desktop launch does not enable phone access by default.
Choose a writable capture folder in guided setup; this is on the Windows host, not a phone. Install ASTAP Windows x64 plus D20 (and W08 for a wide camera) from https://www.hnsky.org/astap.htm or https://sourceforge.net/projects/astap-program/files/ . Keep default installer folders when possible, then save paths and verify status in the wizard. Optional streaming needs separately installed FFmpeg: https://ffmpeg.org/download.html . Add its bin directory to your user PATH without replacing other entries; restart the backend after environment changes.
A packaged backend includes DE440s. A source checkout needs data/ephemeris/de440s.bsp downloaded from https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de440s.bsp on this computer before startup. For a missing packaged kernel, repair the package or rebuild with its required input; use the exact server error path. Restart after repair.
Update: stop captures, close the backend normally and back up user data plus any separately selected image folder. Run the newer verified installer and launch again. Uninstall through Windows Installed apps; user data remains. Do not delete it unless intended.
Complete network, Alpaca, site and safety steps in docs/getting-started.en.md, including the firmware warning. On failures read console output or prepare a bug report; review your description/attachments for private information before sending. No new telescope firmware compatibility is implied by this installation guide.
